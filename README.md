# 한이결 소개 페이지

소개·프로필, 세계관, 시작 상황, 주변 인물, 이용 가이드, 플레이리스트로 구성된 정적 사이트입니다.

한이결의 프로필 사진과 주변 인물 6명의 사진이 등록되어 있습니다.

사이트에서 사용하는 사진과 배경 이미지는 모두 이미지체스트의 외부 URL을 참조합니다. 다른 호스팅으로 옮길 때 이미지 파일을 함께 복사할 필요가 없습니다. HTML·CSS·JavaScript와 두 SVG 커서 파일은 같은 폴더에 함께 옮겨 주세요.

상단 메뉴는 유지되고 본문 프레임만 이동합니다. 이미지 클릭 확대, 일반·링크 도트 커서와 서울 거리 배너를 포함합니다.
